# Пояснения к лабораторной работе

## Цель
Реализовать высокочастотную фильтрацию, два метода глобальной пороговой
обработки и адаптивную пороговую обработку с графическим интерфейсом.

## Повышение резкости
Для каждого цветового канала вычисляется:
result = center + a * (n * center - sum(neighbors)).
a — сила, n — 4 или 8. Это исходное изображение плюс высокочастотная составляющая.
При a=1 ядро для 4 соседей:
```
 0 -1  0
-1  5 -1
 0 -1  0
```
Для 8 соседей центр равен 9, остальные коэффициенты -1.
Результат округляется и ограничивается диапазоном 0..255.
Фильтр подчеркивает детали, но может усилить шум и создать ореолы.
Время O(W*H), поскольку размер ядра фиксирован.

## Подготовка для бинаризации
Y = round(0.299R + 0.587G + 0.114B).
Белый пиксель получается при Y > T, иначе черный.

## Оцу
Строится гистограмма из 256 ячеек. Для каждого порога вычисляются
численности двух классов и их средние. Максимизируется
n0*n1*(mean0-mean1)^2 — межклассовая дисперсия с опущенным постоянным
нормирующим множителем. При равном максимуме выбирается первый порог.
Для однотонного изображения порог равен его яркости, результат черный.
Время O(W*H + 256).

## Итеративный глобальный порог
Начальный порог равен средней яркости. Пиксели делятся на классы Y<=T и Y>T.
Новый порог — полусумма средних классов. Остановка при изменении менее 0.01,
пустом классе или после 100 итераций. Подсчет ведется по гистограмме.
Время O(W*H + 256*число итераций).

## Адаптивный порог
Для каждого пикселя T(x,y) = mean(window) - C.
Окно имеет размер (2r+1)*(2r+1); у границ берется его пересечение с изображением,
и среднее делится на фактическое число пикселей. Пиксели на границах не пропускаются.
Интегральная таблица хранит суммы прямоугольников от начала изображения.
Сумма любого окна вычисляется четырьмя обращениями к таблице.
Время O(W*H), дополнительная память O(W*H).
Это выбранная реализация, ее соответствие лекции пока не подтверждено.

## Тестовая база
blurred.png — искусственно размытые геометрические фигуры.
uneven.png — темные символы на фоне с градиентом яркости.
imbalanced.png — маленький яркий объект на фоне с двумя уровнями яркости.
three-levels.png — фон и два объекта разной яркости.
Тесты двух глобальных методов специально имеют разную долю классов.
Оценивать качество нужно относительно цели: например, выделение только самого
яркого объекта или выделение обоих объектов. Нет обещания, что один алгоритм
всегда лучше другого.
