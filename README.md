# Лабораторная работа 3. Вариант 8

## Запуск
Установите актуальную LTS-версию Node.js. В папке проекта:

```sh
npm install
npm run dev
```
Откройте адрес, который напечатает Vite.

Проверка типов и production-сборка:
```sh
npm run build
npm run preview
```
Для сдачи нужно опубликовать содержимое dist на статическом хостинге.
Проект не опубликован автоматически. Не открывайте index.html двойным щелчком.

## Что реализовано
- Высокочастотная фильтрация: повышение резкости на основе Лапласиана с 4 и 8 соседями.
- Два глобальных метода: Оцу и итеративный порог (среднее двух классов).
- Адаптивный порог по локальному среднему, ускоренный интегральным изображением.
- Clamp и Reflect для свертки; прозрачность сохраняется.
- Загрузка, сравнение до/после, параметры, сохранение результата PNG.
- Четыре синтетических тестовых изображения в public/tests.
- Обработка в одном Web Worker, чтобы не блокировать интерфейс.

Готовые библиотечные фильтры не используются. Canvas нужен только для декодирования,
чтения/записи RGBA и отображения. Обработка выполняется вручную над линейными
типизированными массивами, представляющими двумерную сетку пикселей.

## Важное ограничение
В задании адаптивный алгоритм должен совпадать с лекцией. Лекция не предоставлена.
Здесь выбран порог mean(window) - C. Если в лекции другой алгоритм, эту функцию
необходимо заменить. Не заявляйте полное соответствие этому пункту без сверки.
Дополнения для группы 10А учтены в части Оцу, SAT и двух способов обработки краев.
Пункты для других вариантов (CLAHE, морфология, Кэнни) намеренно не добавлены.
Многопоточная свертка для максимальной оценки не реализована: один worker только
отделяет вычисления от UI. Гистограмм и аналитического отчета с реальными
результатами нет; их не следует считать автоматически выполненными.

## Структура
src/App.tsx — интерфейс, загрузка/сохранение.
src/pixels.ts — буфер, доступ к пикселям, края, оттенки серого.
src/algorithms.ts — алгоритмы без зависимости от React и Canvas.
src/worker.ts — вызов алгоритмов в фоновом потоке.

## Как проверить
1. Открыть размытый тест, применить обе резкости при силе 0.3–1.
2. Выбрать Clamp и Reflect, сравнить край изображения.
   У ядра 3x3 эти два варианта отражения могут давать одинаковые результаты:
   Reflect здесь повторяет крайний пиксель.
3. На тестах с маленьким объектом и тремя уровнями сравнить пороги Оцу
   и итеративного метода. Записать порог, оценить нужный объект, а не только фон.
4. На тесте с неравномерным освещением сравнить глобальные методы и
   адаптивный метод (окно 31, C=10). Попробовать другие окна.
5. Сохранить результаты и использовать их в отчете. Добавить собственные фотографии:
   синтетические тесты не заменяют проверку на реальных изображениях.

Сборка и браузерные испытания в среде создания архива не выполнялись.
